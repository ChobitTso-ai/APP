## 全域規格

每一張都要遵守：

| 項目 | 規格 |
|---|---|
| 格式 | 獨立 `.svg` 檔，一個項目一個檔。不要外部參照、不要 `<image>`、不要 base64 |
| viewBox | 單顆牙 `0 0 360 560`／多顆牙 `0 0 720 560`／四格圖 `0 0 960 280` |
| 背景 | 透明，不要畫背景矩形 |
| **文字** | **整份 SVG 不可出現 `<text>` 元素**，不要任何文字、字母、數字標註 |
| 樣式寫法 | 用 inline 的 `fill=`／`stroke=` 屬性。不要 `<style>` 區塊、不要 CSS class |
| 解剖層次 id | `enamel` `dentin` `pulp` `pdl` `bone` `gingiva` `lesion` `arrow` |
| 檔案大小 | 每個檔案 < 60KB |
| 視角 | 上顎中門齒的唇舌向剖面（labio-lingual cross-section），要看得到齒釉質／象牙質／牙髓腔與根管／牙周韌帶／齒槽骨／牙齦 |

兩個規格的理由，請務必遵守：

- **不可有文字**：App 要中英文切換，標籤由 HTML 渲染。圖上有字就得畫兩套。
- **不可用 CSS class**：多張圖會被 inline 進同一個頁面，class 會互相汙染。

## 最關鍵的一致性要求

先完成 `01 base-closed-apex.svg`。之後**每一張單顆牙的圖，牙齒、牙周韌帶、
齒槽骨、牙齦的 path 資料必須原封不動沿用 01**，只有「傷害的部分」不同。

這些圖在 App 裡會並排比較，外形只要不一致，整批就失去診斷鑑別的意義。
