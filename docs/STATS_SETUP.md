# 統計後端設定步驟（Google 試算表 + Apps Script）

首頁的造訪／不重複訪客／登入／各 App 開啟次數，存在**你自己的 Google 試算表**裡。
以下步驟做一次就好，約 5 分鐘。

> 隱私：只存匿名計數，不記錄 IP、不記錄任何個人資料。訪客瀏覽器裡只留一個
> 隨機字串當「這台裝置」的記號，用來算不重複人數。

---

## 步驟 1：建立試算表

1. 開 https://sheets.google.com → 建立**空白試算表**
2. 檔案名稱改成好認的，例如 `App 中心統計`

## 步驟 2：貼上程式碼

1. 在試算表上方選單點 **擴充功能 → Apps Script**
2. 會開一個新分頁，裡面有預設的 `function myFunction() {}` ——**全部刪掉**
3. 把 [`docs/stats-backend.gs`](stats-backend.gs) 的**全部內容**複製貼上
4. 按上方 💾 儲存（專案名稱隨便取，例如 `統計後端`）

## 步驟 3：部署成網頁應用程式

1. 右上角點 **部署 → 新增部署作業**
2. 左邊齒輪 ⚙️ **選取類型 → 網頁應用程式**
3. 設定三個欄位：
   - **說明**：隨便填，例如 `v1`
   - **執行身分**：**我**（你自己的帳號）
   - **具有存取權的使用者**：**任何人** ← ⚠️ 這個要選「任何人」，
     不是「任何擁有 Google 帳戶的人」。訪客沒登入 Google 也要能計數。
4. 按 **部署**
5. 第一次會跳授權：**授權存取 → 選你的 Google 帳號 → **
   出現「Google 尚未驗證這個應用程式」時，點左下 **進階 → 前往「統計後端」（不安全）**
   → **允許**。（這是你自己寫的腳本存取你自己的試算表，正常現象。）
6. 部署完成後會顯示一個**網頁應用程式網址**，長得像：
   ```
   https://script.google.com/macros/s/AKfycb.....................《很長》.../exec
   ```
   **按「複製」，把這串網址貼回對話給 Claude。**

## 步驟 4：Claude 接上前端

把網址給 Claude 後，Claude 會把它填進 `app.js` 最上方的 `STATS_ENDPOINT`，
推上 PR 合併後就會開始計數，數字顯示在首頁。

---

## 之後怎麼看數據

- **試算表**：直接打開，`stats` 工作表會列出每個項目與次數
- **首頁**：登入後標題下方會顯示「造訪 X 人次 · 不重複 Y · 登入 Z」，
  每張 App 卡片右下角顯示自己的開啟次數

## 疑難排解

| 狀況 | 處理 |
| --- | --- |
| 首頁看不到統計列 | `STATS_ENDPOINT` 還沒填，或後端回應失敗——統計失敗不影響網站其他功能 |
| 數字沒動 | 部署時「具有存取權的使用者」要選**任何人**；改完要**重新部署**（部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署） |
| 改了程式碼沒生效 | 同上，Apps Script 改完一定要建立**新版本**重新部署 |
| 想歸零重算 | 打開試算表，把 `stats` 工作表的數字欄改成 0 即可 |
