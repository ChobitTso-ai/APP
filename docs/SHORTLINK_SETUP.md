# 縮網址後端設定步驟（Google 試算表 + Apps Script）

「縮網址」App 的短網址清單與點擊次數，存在**你自己的 Google 試算表**裡。
以下步驟做一次就好，約 5 分鐘，跟當初設定「使用統計」「即時投票」是同一套流程。

```
短網址清單與點擊次數  →  你的 Google 試算表
查代號、計次的那段程式  →  你的 Google Apps Script（docs/shortlink-backend.gs）
網站本身              →  GitHub Pages（App 中心本來就在這，不會變）
```

短網址長這樣：

```
https://chobittso-ai.github.io/APP/s/?rct
```

> 網址的長度受限於 GitHub Pages 的網域（`chobittso-ai.github.io/APP`）。
> 想要 `xx.tw/rct` 這種更短的，要另外買網域綁到 GitHub Pages，屬於另一件事。

---

## ⚠️ 先看這一段：兩道門

| | 誰能做 | 要什麼 |
| --- | --- | --- |
| **點短網址**（轉址頁 `s/`） | 任何人 | 什麼都不用，**刻意不加登入**（同事用手機相機掃 QR，開的是沒登入過的瀏覽器） |
| **建立／修改／刪除／看清單**（App 中心的「縮網址」） | 有「建立金鑰」的人 | App 中心登入 **＋** 建立金鑰 |

**為什麼要另外一組金鑰？** App 中心的 NCKUH / ENDO 帳密寫在公開的網頁原始碼裡，等於公開的。
如果只靠它，任何人都能用 `chobittso-ai.github.io/APP/s/…` 這個看起來像本科的網址，
轉到釣魚網站。建立金鑰存在 Apps Script 的「指令碼屬性」裡，**不在程式碼、不進 repo**，
只分享給要建立短網址的同事。

另外：

- **短網址任何拿到的人都點得開**——不要把病患資料放進目標網址或標題。
- 點擊紀錄只記「時間＋代號」，**不記是誰點的**（Apps Script 本來也拿不到點擊者的 IP）。
- 只接受 `http://`、`https://` 的目標網址。

---

## 步驟 1：建立試算表

1. 開 https://sheets.google.com → 建立**空白試算表**
2. 檔案名稱改成好認的，例如 `縮網址`

> 建議跟「App 中心統計」「投票結果」用**不同的試算表**，比較好整理。

## 步驟 2：貼上程式碼

1. 在試算表上方選單點 **擴充功能 → Apps Script**
2. 會開一個新分頁，裡面有預設的 `function myFunction() {}` ——**全部刪掉**
3. 把 [`docs/shortlink-backend.gs`](shortlink-backend.gs) 的**全部內容**複製貼上
4. 按上方 💾 儲存（專案名稱隨便取，例如 `縮網址後端`）

## 步驟 3：執行 setup，拿到建立金鑰（這步不能省）

1. 上方的函式下拉選單選 **`setup`** → 按 **▶ 執行**
2. 第一次會跳授權：**審查權限 → 選你的 Google 帳號 →**
   出現「Google 尚未驗證這個應用程式」時，點左下 **進階 → 前往「縮網址後端」（不安全）**
   → **允許**。（這是你自己寫的腳本存取你自己的試算表，正常現象。）
3. 下方「**執行記錄**」會出現一行：
   ```
   建立金鑰：abcd-2345　（請記下來，分享給要建立短網址的同事）
   ```
   **把這組金鑰記下來。** 試算表裡也會多出「短網址」「點擊紀錄」兩個工作表。

> 不想用自動產生的？到左側 ⚙️ **專案設定 → 指令碼屬性**，把 `ADMIN_KEY` 改成你要的字串即可。

## 步驟 4：部署成網頁應用程式

1. 右上角點 **部署 → 新增部署作業**
2. 左邊齒輪 ⚙️ **選取類型 → 網頁應用程式**
3. 設定三個欄位：
   - **說明**：隨便填，例如 `v1`
   - **執行身分**：**我**（你自己的帳號）
   - **具有存取權的使用者**：**任何人** ← ⚠️ 要選「任何人」，
     不是「任何擁有 Google 帳戶的人」。點短網址的人沒登入 Google 也要能用。
4. 按 **部署**
5. 部署完成後會顯示一個**網頁應用程式網址**，長得像：
   ```
   https://script.google.com/macros/s/AKfycb.....................《很長》.../exec
   ```
   **按「複製」，把這串網址貼回對話給 Claude。**（建立金鑰**不用**給 Claude，也不要貼進 repo。）

## 步驟 5：接上前端

Claude 會把網址填進 `apps/short-link/config.js` 的 `SHORTLINK_ENDPOINT`，合併後約 1 分鐘生效。

> 想自己改也可以：在 GitHub 網頁打開 `apps/short-link/config.js` → ✏️ 編輯 →
> 把網址貼進 `window.SHORTLINK_ENDPOINT = '';` 的引號裡 → Commit 到 `main`。

## 步驟 6：試用

1. App 中心 → **縮網址** → 輸入建立金鑰（只要第一次）
2. 貼一個網址、按「建立短網址」
3. 用手機相機掃畫面上的 QR code，應該會直接開到目標網址
4. 回到縮網址頁按「🔄 重新整理」，那一筆的點擊次數會變成 1

## 怎麼用

| 想做的事 | 怎麼做 |
| --- | --- |
| 建立短網址 | 貼上目標網址；代號可以自訂（例如 `rct-2026`），留空自動產生 5 碼 |
| 拿 QR code | 建立後直接顯示；清單每一筆的「🔳 QR」可下載 PNG（下方可加標題與網址，方便印）、SVG（印刷放大不糊），或複製圖片直接貼到 LINE／簡報 |
| 改連到哪 | 清單的「✏️ 編輯」改目標網址——**已經印出去的 QR code 也會跟著改**，代號不能改 |
| 看點擊次數 | 清單上每一筆都有總次數、近 7 天、最後點擊時間；可依「點擊最多」排序 |
| 預覽目的地 | 在短網址最後加 `+`（例如 `…/s/?rct+`）只顯示目的地、不跳轉、不計次 |
| 直接在試算表加 | 在「短網址」工作表新增一列，填**代號**與**目標網址**兩欄就能用（其他欄可空白） |
| 刪除 | 清單的「🗑 刪除」——短網址與 QR code 立刻失效；「點擊紀錄」工作表的歷史保留 |

### 試算表裡有什麼

| 工作表 | 內容 |
| --- | --- |
| **短網址** | 每個短網址一列：代號／目標網址／標題／建立者／建立時間／更新時間／點擊次數／最後點擊 |
| **點擊紀錄** | 每點一次一列：時間／代號。想看「哪天點最多」可以用樞紐分析表 |

## 金鑰管理

| 狀況 | 在 Apps Script 執行 |
| --- | --- |
| 忘記金鑰 | `showKey`（顯示在執行記錄） |
| 金鑰外流、同事離職 | `resetKey`（換一組新的，舊的立刻失效；大家下次開縮網址頁會被要求重新輸入） |

金鑰連續輸錯 30 次，15 分鐘內會全部擋下（防亂猜）。

---

## 容量

用 Google 的免費額度。科內日常使用（每天數十到數百次點擊）應該碰不到上限，
但**確切配額以 Google 官方的「Apps Script 配額」說明為準**（這裡沒有實測過上限）。

速度：每次點短網址都要問一次 Apps Script，通常 1～3 秒；隔一陣子沒人用時
（Apps Script 冷啟動）會更久，轉址頁會顯示「正在前往目的地…」，超過 3 秒會提示稍候。
這是用免費後端的代價——要做到瞬間跳轉得換付費的轉址服務或自己的伺服器。

---

## 更新後端程式碼（改版時）

1. 試算表 → **擴充功能 → Apps Script**
2. 把編輯器內容**全選刪掉**，貼上新版 `shortlink-backend.gs`，儲存 💾
3. **部署 → 管理部署作業** → 右上角 ✏️ 鉛筆 → **版本**選「**新版本**」→ **部署**
   （⚠️ 只存檔不重新部署的話，線上跑的還是舊版）

**網址不會變，金鑰也不會變**（存在指令碼屬性，不在程式碼裡）。

## 疑難排解

| 狀況 | 處理 |
| --- | --- |
| 縮網址頁顯示「還沒接上縮網址後端」 | `apps/short-link/config.js` 的 `SHORTLINK_ENDPOINT` 還沒填 |
| 「後端還沒設定建立金鑰」 | 步驟 3 的 `setup` 沒執行 |
| 「金鑰不正確」 | 執行 `showKey` 看目前的金鑰；可能有人執行過 `resetKey` |
| 「連不上縮網址後端」 | 部署時「具有存取權的使用者」要選**任何人**；改完程式一定要建**新版本**重新部署 |
| 點短網址出現「找不到這個短網址」 | 代號打錯，或那一列被刪了 |
| 手動在試算表加的代號 `007` 變成 `7` | 那格被當成數字了：選取整欄 → 格式 → 數值 → **純文字**，再重打一次（setup 建立的工作表已預設純文字） |
