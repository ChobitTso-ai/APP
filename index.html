加到手機桌面

加入後桌面會多一個「App 中心」圖示，點開就是全螢幕，像一般 App 一樣。

這個 App 的內建瀏覽器不能加入主畫面，請先改用 Safari 或 Chrome 打開這一頁。
用瀏覽器開啟
  1. 用 Safari 開啟這一頁（iOS 16.4 以上用 Chrome 也可以）。
  2. 點「分享」。 iPhone 在畫面下方；iOS 26 若沒看到，先點網址列旁的再找。
  3. 往下滑，點「加入主畫面」。
  4. 右上角點「加入」，完成。
  1. 用 Chrome 開啟這一頁。
  2. 點右上角選單。
  3. 點「加到主畫面」或「安裝應用程式」。
  4. 按「安裝」（或「新增」），完成。
