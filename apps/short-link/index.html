💡 使用說明
  • 點短網址的人不用登入，同事用手機相機掃 QR code 就能直接到目的地。
  • 目標網址可以隨時改（按「編輯」）：QR code 已經印出去也沒關係，掃了會到新網址。代號不能改。
  • 點擊次數：每打開一次 +1（同一個人點兩次算兩次），只記時間，不記是誰點的。 點過之後回到這頁按「🔄 重新整理」就會更新。
  • 不確定短網址會連到哪？在網址最後加一個 +（例如 …/s/?abc+），只會顯示目的地、不會跳轉。
  • 資料存在管理者的 Google 試算表「短網址」工作表，也可以直接在試算表新增一列（填代號與目標網址即可）。
  • ⚠️ 不要把病患資料放進網址或標題——短網址任何拿到的人都點得開。
